# DBS401 - Hospital Management System

## Mô tả
Web quản lý bệnh viện (Global Hospitals) - PHP + MariaDB

## Yêu cầu
- OS: Ubuntu/Kali/Debian
- Apache2, MariaDB, PHP

## Cài đặt tự động (One-click)
```bash
git clone https://github.com/duy337-hdg/dbs401-hospital.git
cd dbs401-hospital
chmod +x setup.sh
sudo bash setup.sh
```

## Truy cập
Sau khi chạy script, vào: http://127.0.0.1/hospital
